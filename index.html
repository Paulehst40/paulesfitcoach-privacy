Datenschutzerklärung

Diese App speichert alle Daten ausschließlich lokal auf deinem Gerät. Es werden keine personenbezogenen Daten an den Entwickler oder Dritte übertragen.

1. Verantwortlicher

Paule's Fit Coach

2. Welche Daten werden verarbeitet?

Die App verarbeitet ausschließlich Daten, die du selbst eingibst:

  • Trainingseinheiten (Datum, Übungen, Sätze, Gewicht, Wiederholungen)
  • Trainingspläne und Übungs-Bibliothek
  • Körperdaten (Gewicht, Körperfettanteil)
  • Profilbild (optional, aus deiner Galerie)
  • App-Einstellungen (Wochenziel, Ruhe-Timer, Farbschema)

3. Wo werden die Daten gespeichert?

Alle Daten werden ausschließlich lokal auf deinem Gerät gespeichert – in einer SQLite-Datenbank und den App-Einstellungen. Es gibt keinen Server, keine Cloud und keine externe Datenbank.

✓ Kein Server ✓ Keine Cloud ✓ Kein Internet erforderlich

4. Datenweitergabe an Dritte

Es findet grundsätzlich keine Weitergabe deiner Daten an Dritte statt.


Ko-fi (Spenden-Link): Wenn du in der App auf „Kaffee spendieren" tippst, wirst du zum externen Dienst Ko-fi (ko-fi.com) weitergeleitet. Diese Weiterleitung erfolgt ausschließlich auf deine aktive Initiative. Die App selbst übermittelt dabei keine Daten. Für Ko-fi gilt deren eigene Datenschutzerklärung.

5. Berechtigungen der App

  • Speicher / Medien: Nur für den Datei-Export (Backup), den Import einer Backup-Datei sowie das optionale Profilbild – jeweils nur auf deine aktive Anforderung.
  • Internet: Die App benötigt keine Internet-Berechtigung und hat keinen Zugriff auf das Netzwerk.

6. Datenlöschung

Alle Daten werden vollständig gelöscht, wenn du die App deinstallierst. Einzelne Trainingseinheiten kannst du jederzeit manuell in der App löschen. Du hast jederzeit die vollständige Kontrolle über deine Daten.
